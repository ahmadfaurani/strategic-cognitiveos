## 3. Why 3 FTE (Not 5)

Original 5-FTE model assumed multi-tenant RLS build as critical path. Teras as infrastructure layer changes the math:
- No DevOps hire — Teras manages infrastructure
- No multi-tenant build — Teras handles deployment isolation
- No API gateway build — Teras provides it
- No governance infrastructure build — Teras provides it, VoronCitadel integrates

Remaining dependencies (application-layer only):
1. UI/UX + white-labelling — HoE + Jr Backend
2. AI RAG pipeline — Teras provides RAG infrastructure, VoronCitadel configures
3. Connector suite — Jr Backend under HoE direction

## 4. POC Load Math

Each POC over 8 weeks: 80-120 hours
- Weeks 1-2: 20-30 hours onboarding
- Weeks 3-6: 5-10 hours/week evaluation support
- Weeks 7-8: 10-15 hours evaluation review

7 POCs staggered (2-3 new/month) = 40-60 hours/week sustained = 0.75-1.0 FTE
3 paying customers: ~24 hours/week = 0.4 FTE
Total customer-facing: ~1.2-1.4 FTE → CSE (1.0) + Jr Backend (0.3-0.4)
