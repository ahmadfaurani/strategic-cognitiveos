# OPP-20260822-002 — MQL Framework as Reusable Standard

## Opportunity

The MQL framework (DEC-20260822-004, DEC-20260822-005) is being designed for VoronCitadel GTM. Once agreed at Tuesday's meeting, the same framework — MQL = "requested a meeting," cost-per-MQL, marketing-sales handoff — can be applied as the standard measurement model for all 3 products:

1. **VoronCitadel** — first application (Tuesday Aug 25)
2. **chain:SENTRY** — same funnel structure, same KPIs
3. **GovSec TIP** — same funnel structure, same KPIs

## Value

- Eliminates per-product GTM measurement design
- Creates comparable metrics across products
- One framework, three product applications
- Compounding capability (§6.5) — each product adoption reinforces the standard

## Conditions

- Framework must be agreed at Tuesday meeting first
- Per-product MQL targets will differ (different market sizes, different price points)
- Channel attribution rule must be resolved before cross-product application

## Confidence

Medium — framework is sound but not yet agreed. Tuesday meeting is the gate.
