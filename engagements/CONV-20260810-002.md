## GovSec TIP v3.0 — Threat Visualization + Executive Dashboard (August 2026)

- Threat Visualization module: integrated Threat Map and Threat Graph views
- Executive Dashboard: leadership-focused posture scoring, threat metrics, response-time analytics, sector-based insights
- Enhanced dashboard widgets: Geographic Intelligence and Correlation Graph visualizations
- Modernized login experience: futuristic secure-channel interface
- Improved navigation: role-based menu organization, expanded API documentation

## GovSec TIP v2.5 — AI Analyst + Threat Hunting + Malaysian Compliance (July 2026)

- AI Analyst: RAG-powered conversational intelligence
- Dynamic Threat Scoring engine for risk prioritization
- Threat Hunting Workbench with saved and scheduled hunts
- MITRE ATT&CK coverage analysis and heatmaps
- CVE and CISA KEV integration for vulnerability intelligence
- PDPA compliance: PII detection, redaction, audit logging, retention policies
- Malaysian APT library and Government Organization Structure modules
- Enhanced RBAC enforcement and automated security workflows

## GovSec TIP v2.4 — Core Platform MVP (May 2026)

- Dashboard, Alerts, Cases, Correlations, Indicators, Rules, Audit Logging
- MITRE ATT&CK integration and API Documentation
- Role-based user management and authentication services
- PostgreSQL-backed architecture with React and Node.js technology stack

## GovSec TIP v2.2 — TTP-to-Indicator Pivot + Threat Actor CRUD (April 2026)

- TTP-to-Indicator Pivot: click technique chip → query all global indicators tagged with MITRE technique ID
- Threat Actor CRUD: POST/PUT/DELETE endpoints, ActorModal component
- MITRE ATT&CK Sync: fetches intrusion-set, attack-pattern, relationship from TAXII 2.1
- New DB columns: ttps, stix_id, mitre_group_id on threat_actors table
- On-Demand TTP Endpoint: GET /api/actors/:id/ttps
- TTP Panel in ActorDrawer: IoC/TTP tab switcher with tactic lanes and technique chips
