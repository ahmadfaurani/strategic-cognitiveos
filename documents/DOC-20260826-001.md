# Document Record

PRISM SRS for JPM/BKS. 15 pages, ~40 system requirements, 10 non-functional system requirements.

**Key technical findings:**
- Data platform: PostgreSQL (relational) + Neo4j (graph) + Qdrant (vector)
- Data cascade: COLLECT → REFINE → LAKE → SERVE
- AI/ML: Eternis agent runtime, MTizer sentiment engine, MiroFish content integrity, MEMber Suara STT, prediction ensemble+LLM
- SR-CHT-05: guided-interview service with configurable analytical framework (R.I.S.I.K named)
- Multi-tenant: each engagement = isolated configuration-driven tenant
- R.I.S.I.K build = configuration + extension, not new infrastructure
- Revised build estimate: ~28-35 days (down from ~40-47 URS-based)
