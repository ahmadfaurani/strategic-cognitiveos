# chain:SENTRY Platform Roadmap v2.0

> CONFIDENTIAL — FOR EXECUTIVE AND ENGINEERING REVIEW
> Version 2.0 | August 2026
> Author: Hadri
> Delivered via email 2026-08-19

## Roadmap Phases

| Phase | Window | Objective | Exit Criterion |
|-------|--------|-----------|-----------------|
| Phase 0 — Land & Secure | Days 0–5 | Close exposure, deploy 12 closed gaps | Credentials reissued; release deployed; sweep clean |
| Phase 1 — Pilot Readiness | Weeks 1–4 | Named external investigator, enforced roles, defensible output | Pilot gate passed (9 criteria) |
| Phase 1B — Controlled Pilot | Weeks 5–8 | Real casework under observation | Pilot exit criteria met; continuation decision |
| Phase 2 — Productisation | Months 3–5 | Supportable by non-builders | Recoverability, observability, secret governance, quality debt |
| Phase 3 — Capability Expansion | Month 6+ | Extend boundary where pilot showed cost | Non-EVM tracing, bridges, signing |

## MVP Readiness Scores

- **Implementation readiness: 69%** — engineering largely exists
- **Deployed readiness: 47%** — what a pilot user would meet
- **22-point gap** = 12 closed gaps sitting in an undeployed branch
- **MVP threshold: 85%** — reached during Phase 1, not before

## Phase 0 Deliverables (7 items, all blocking)

0.1 — Revoke and reissue 4 supplier credentials (Security owner)
0.2 — Resolve address-security regression: restore or record (Engineering)
0.3 — Reconstruct release manifest file by file (Delivery lead)
0.4 — Take backup and prove restore into isolated target (Platform ops)
0.5 — Apply organisation backfill + audit-enforcement migrations (Platform ops)
0.6 — Deploy release in controlled window with rollback trigger (Delivery lead)
0.7 — Run post-release verification sweep including anonymous probes (Platform ops)

## Critical Path (M1–M7, non-negotiable)

M1 Exposure closed → M2 Regression decision → M3 Deployment describable → M4 Recovery proven → M5 Schema under control → M6 Closed work serving → M7 Externally reachable

## Sequencing Rules

1. Rotation before reachability (exposure already open)
2. Backup and restore before schema change (migrations alter evidence)
3. Backfill before role-aware retrieval (else records lose visibility)
4. Enforcement before oversight accounts (label ≠ access control)
5. Deploy before verifying (testing old build proves nothing)

## Capacity Risk

Phase 0 concentrates platform-ops + security work into 5 days, sequential. If one person holds both roles, the window is not 5 days. Assess role coverage before committing to a date.
