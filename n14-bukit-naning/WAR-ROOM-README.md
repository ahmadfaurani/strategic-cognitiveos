N14 Bukit Naning is a **HIGHLY COMPETITIVE 4-CORNER SEAT**. In 2022, BN won with only 38.14% — the lowest winning share in Johor. Combined opposition (PH+PN+BERSAMA = 61.24%) >> BN (38.14%).

**2026 Path to Victory:**

2. Benefit from continued 4-way split
