# Strategic CognitiveOS

**Phase 1 — Strategic Memory, Decision and Execution Foundation**

**Strategic Owner:** Ahmad Faurani Jaafar
**Version:** 1.0
**Status:** Foundational Operating Specification

## What This Is

Strategic CognitiveOS is a personal and institutional intelligence system designed to extend the strategic reach of Ahmad Faurani Jaafar while reducing excessive dependency on his direct involvement across every initiative.

It converts fragmented conversations, documents, relationships, decisions and commitments into a connected institutional intelligence environment.

## Repository Structure

```
strategic-cognitiveos/
├── governance/          # Operating principles, decision rights, lifecycle
├── schemas/             # JSON schemas for each record type
├── taxonomy/            # YAML taxonomies (tags, missions, tiers, etc.)
├── templates/           # Markdown templates for each record type
├── strategy/            # Mission, objectives, leadership agenda
├── portfolio/           # Initiatives by tier (flagship, incubation, etc.)
├── memory/               # Conversations, insights, questions, lessons
├── decisions/           # Decision records
├── stakeholders/        # Stakeholder records
├── engagements/         # Engagement records
├── commitments/         # Commitment records
├── actions/             # Action records
├── opportunities/       # Opportunity records
├── intelligence/        # Intelligence records
├── artifacts/           # Artifact records
├── risks/               # Risk records
├── outcomes/            # Outcome records
├── indexes/             # Navigation indexes
└── archive/             # Superseded and completed records
```
