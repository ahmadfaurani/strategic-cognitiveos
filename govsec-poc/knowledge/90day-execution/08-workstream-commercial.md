## Commercial Model Components

### 1. Pricing Logic

| Component | Model | Description | Example |
|-----------|-------|-------------|---------|
| **POC Phase** | Fixed-fee per POC | 4-6 week POC with defined scope, KPIs, deliverables | RM 100K-200K per POC |
| **Deployment Phase** | Subscription + Implementation | One-time implementation + annual subscription | RM 500K-1.5M implementation + RM 300K-800K/year |
| **Scaling Phase** | Tiered subscription | Based on users, data volume, features | RM 1M-2M/year per agency |
| **Support** | Tiered SLA | Bronze/Silver/Gold support packages | RM 50K-200K/year |

---

### 2. Revenue Sharing Model

| Scenario | CSM Share | Aras Share | Rationale |
|----------|-----------|------------|-----------|
| **Government Accounts** (MINDEF, NACSA, agencies) | 60% | 40% | CSM branding critical for government trust |
| **GLC/Regulated Sector** (BNM, MCMC, TNB, Petronas) | 50% | 50% | Equal contribution (CSM network + Aras delivery) |
| **Private Sector** (Banks, telcos, enterprises) | 40% | 60% | Aras delivery heavier, CSM network less critical |
| **Training/Educational** (UPNM, universities) | 50% | 50% | Joint IP, co-delivery model |

**Revenue Recognition:**
- POC revenue: Recognized upon POC completion + acceptance sign-off
- Deployment revenue: 50% upfront, 50% upon go-live
- Subscription revenue: Recognized annually (upfront payment)
