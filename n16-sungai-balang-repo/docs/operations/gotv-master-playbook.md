### Vehicle Fleet Composition

| Vehicle Type | Count | Capacity | Use Case |
|--------------|-------|----------|----------|
| Personal Cars (volunteer) | 40 | 4 passengers each | General GOTV, short routes |
| Personal Cars (staff) | 10 | 4 passengers each | Command staff, flexible deployment |
| Rental Vans (40-seater) | 5 | 40 passengers each | Bulk transport, elderly groups, remote PDs |
| **Total Capacity** | **55** | **~320 passengers/round** | Multiple rounds throughout day |

**Assumptions:**
- Average 2.5 rounds per vehicle (morning, midday, afternoon)
- Total transport capacity: ~800 voters
- Target: Transport 15-20% of PH voters = ~1,800-2,400 voters
- **Gap identified:** Need additional rounds or vehicles

**Mitigation:**
- Extend vehicle hours (06:00-17:00 = 11 hours = 4-5 rounds possible)
- Recruit 10 additional drivers (target: 60 total)
- Prioritise high-value voters (firm PH supporters, elderly, disabled)

### Driver Protocols

**Pre-Day Checklist:**
```
[ ] Vehicle inspection (fuel, brakes, tires, AC)
[ ] Phone charged + power bank
[ ] Route map printed (backup if GPS fails)
[ ] Passenger list (names, phones, pickup times)
[ ] Emergency contact numbers (Transport Coordinator, Command)
[ ] Water + snacks for passengers
[ ] Umbrellas/raincoats (weather contingency)
```

**During Operations:**
- Arrive at pickup point 5 minutes early
- Wait maximum 5 minutes (note no-shows, report to command)
- Assist elderly/disabled passengers (door-to-door if needed)
- Maintain passenger manifest (who boarded, which polling station)
- Report completion to Transport Coordinator after each round
- Refuel as needed (receipts for reimbursement)

**Safety Protocols:**
- No speeding or traffic violations (campaign liability)
- No political discussions with opposing voters (incidents risk)
- Emergency contact: Transport Coordinator (immediate reporting)
- Accident protocol: Call 999, notify command, preserve evidence

## 🚨 GOTV CONTINGENCY PLANS

### Scenario 1: Low Morning Turnout (<12% by 09:00)

**Triggers:**
- 09:00 turnout report shows <12% cumulative
- Multiple PDs report "quiet" openings
- Weather poor (rain deterring voters)

**Response:**
1. Escalate to Tier Commanders (investigate local factors)
2. Deploy runners to key PDs (in-person assessment)
3. Accelerate transport schedule (more frequent pickups)
4. WhatsApp urgency blast ("Undi Pagi Elak Panas/Hujan")
5. Extend polling hours communication (remind 07:30-17:00)

---

### Scenario 2: Transport Breakdown (Vehicle Failure)

**Triggers:**
- Driver reports breakdown/incident
- Multiple no-shows at pickup point
- Passenger complaints about delays

**Response:**
1. Driver calls Transport Coordinator immediately
2. Coordinator dispatches backup vehicle (nearest available)
3. Passengers notified of delay + ETA (manage expectations)
4. Broken vehicle towed/repaired (post-election)
5. Incident logged (insurance/reimbursement)

**Prevention:**
- Pre-day vehicle inspection (mandatory)
- 10% vehicle buffer (55 vehicles for ~50 needed)
- Driver hotline (24/7 during GOTV operations)

---

### Scenario 3: Polling Station Incident (Long Queues, Machine Failure)

**Triggers:**
- Polling agent reports queue >60 minutes
- SPR equipment failure (ink, forms, ballots)
- Confrontation between voters (political tension)

**Response:**
1. Agent notifies Legal Coordinator immediately
2. Legal Coordinator contacts SPR returning officer
3. Rapid Response Team deploys (investigate, document)
4. Voters notified of delays (WhatsApp, social media)
5. Escalate to State Election Director if unresolved >30 min

**Voter Communication:**
```
⚠️ UPDATE: [Polling Station] experiencing delays due to [reason].

SPR sedang selesaikan. Undi anda tetap penting — tunggu jika boleh.

Alternatif: Pertimbangkan undi lewat (15:00-16:00) untuk elak ramai.

Kami update setiap 30 minit. Terima kasih bersabar! 🙏
```

---

### Scenario 4: PH Behind Target (-10% or More at 13:00)

**Triggers:**
- 13:00 turnout report shows >10% gap vs. target
- Multiple Tier 1/2 PDs underperforming
- Transport capacity insufficient

**Response:**
1. War Room Director declares "Code Red" (all-hands emergency)
2. Activate reserve volunteers (on-call list, 50+ available)
3. Extend transport hours (17:00 → 18:00 if needed)
4. Personal calls from candidate to top 100 supporters (VIP GOTV)
5. Social media urgency ("Kita Ketinggian — Undi Sekarang!")
6. Door-knock surge (nearby PH supporters, 2-hour blitz)

**Escalation Ladder:**
| Time | Gap | Action |
|------|-----|--------|
| 11:00 | -10% | Tier Commanders investigate |
| 13:00 | -10% | Code Red declared, reserves activated |
| 15:00 | -10% | Candidate personal calls, door-knock surge |
| 16:00 | -5% | Final transport wave, all-hands push |
