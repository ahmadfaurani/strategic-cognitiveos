**Classification:** TLP:AMBER  
**Document ID:** CSM-WS-003  
**Alignment:** KB-90DAY-002 (Phase Breakdown)

---

## 📊 Overview

This document outlines the **3-phase, 90-day execution plan** for CSM-Platform partnership mobilization. This replaces the previous 14-week model with a sales kit-aligned approach focused on speed and revenue outcomes.

### Core Principles

| Principle | Operational Guidance |
|-----------|---------------------|
| **Speed > Perfection** | Every activity must map to revenue outcome, positioning, or scale |
| **No CSM Capex** | Platform funds infrastructure; CSM provides branding + network access |
| **30% Conversion Minimum** | Pre-negotiate deployment terms during POC phase |
| **Joint IP (50/50)** | Co-development, co-ownership, CSM branding |
| **Daily Execution Momentum** | Use this plan for daily task guidance, not weekly review |
