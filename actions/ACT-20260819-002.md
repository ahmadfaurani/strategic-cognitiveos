# Action

Monitor the Honcho deriver's processing performance after switching from Qwen3.5-397B-A17B to Qwen3.6-35B-A3B. The deriver processed 833 work units at ~15s each on the 397B model. With 3B active params (vs 17B), the expected improvement is ~10x throughput.

## Required Output

A comparison log entry with:
- Per-unit processing time on new model (measured from docker logs)
- Total queue completion time for a measurable batch
- Comparison against the 397B baseline (~15s/unit, ~4h for 833 units)
- Verdict: does the ~10x improvement hold?

## Owner

Ember (automated monitoring via heartbeat)

## Completion Evidence

Log entry in `memory/2026-08-19.md` with measured times and comparison table.

## Dependencies

Sufficient deriver queue volume — needs new messages flowing into Honcho to trigger processing. If the queue is empty, measurement waits until next session activity generates work units.
