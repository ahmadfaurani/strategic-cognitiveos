# Action

Reconstruct the release manifest file by file. The current deployment is a basis commit + 8 additive files + 43 uncommitted modifications — not a clean checkout of any single commit. A release manifest generated from the repository alone will misdescribe the deployment.

## Required Output

1. Manifest listing every file with:
   - Origin (which commit/file it comes from)
   - Destination state (what the deployment actually contains)
   - Whether the file is committed, additive, or uncommitted modification
2. Address-security regression decision (M2) recorded explicitly
3. Manifest approved by a named delivery lead
4. Build identity established — the deployment is now describable
