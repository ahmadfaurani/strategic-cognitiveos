# Action: Draft Staleness Triage

## Required Output

Draft count reduced to actionable inventory (<30). Stale drafts archived. 30-day draft→active lifecycle rule documented in governance.

## Context

- 86 draft records (58% of 148)
- Status distribution: 86 draft, 30 active, 22 completed, 5 in-progress, 4 open, 1 validated
- No lifecycle enforcement for drafts that never progress

## Triage Categories

1. **Completed-but-unmarked:** Drafts where work was actually done → update status to completed
2. **Stale:** Drafts older than 30 days with no activity → archive
3. **Actionable:** Drafts still relevant → advance to active or in-progress
4. **Superseded:** Drafts replaced by newer records → mark superseded

## Steps

1. List all 86 drafts sorted by created_at
2. For each: check if related work was completed (grep for evidence in other records)
3. Categorise: completed / stale / actionable / superseded
4. Update statuses accordingly
5. Document 30-day draft lifecycle rule in governance

## Verification

- Draft count < 30 (actionable only)
- Archived drafts in archive/ with status change
- 30-day lifecycle rule documented
