context: "LSN records were being created but not consistently entering the deriver pipeline. Some lessons lived only as daily file notes, not as core memory. DAF wants every lesson to be part of the persistent memory system."
decision: "All LSN (lesson) records are mandatory deriver-qualified items. Every lesson must go through the memory deriver pipeline and become part of core memory. LSN records must include deriver_status and core_memory fields. This is a binding policy change."
rationale: "Lessons that exist only as files on disk are not part of the cognitive system's active memory. The deriver pipeline is what makes them retrievable, connected, and actionable. Without deriver qualification, lessons degrade to documentation rather than learning."
