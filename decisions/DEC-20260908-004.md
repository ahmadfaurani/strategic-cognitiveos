# DEC-20260908-004 — Canonical Repository Designation + Taxonomy Protocol

## Decision

**Canonical repository:** `github.com/ahmadfaurani/strategic-cognitiveos` is the system of record for the overall workstream. All strategic state — decisions, actions, documents, intelligence products, stakeholder registry, indexes — is authoritative here and only here.

**Branch model (effective 2026-09-08):**

| Branch | Role | Policy |
|--------|------|--------|
| `main` | Canonical records | All strategic commits; schema+taxonomy validation required |
| `memory-mirror` | Agent continuity mirror (Ember/dreaming cycle) | Renamed from `phone-farm-intel`; remote ref deleted; no config/script dependents (verified before rename) |
| workspace-root `main` | Archived fossil (Apr–Jun fork) | HOLD — never push; candidate for deletion after F5 review |
| New automation branches | — | Must declare purpose in first commit message |

**Taxonomy Index Development Protocol (5 rules, detailed in DOC-20260908-006):**
1. **Vocabulary is validator-gated** — no tag/namespace value without a `taxonomy/*.yaml` entry and a passing validator run in the same commit.
2. **Commit-time index discipline** — every record lands with its index row; orphan scans weekly via SOP-AV-001; target <5% orphaned (baseline: 80/570 = 14%).
3. **Single-source rule** — workspace-root and satellite repos hold working artifacts only; strategic state gets a CognitiveOS record with provenance link back.
4. **Quarterly reconciliation** — full index rebuild against records on disk (next: Oct 1), preserving human commentary blocks.
5. **Declared-purpose branches** — no anonymous automation branches.
