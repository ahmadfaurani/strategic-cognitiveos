# Context

VoronCitadel POC Mode requires deployment isolation for 6-7 POC customers + 3 paying customers. Three options were assessed:

- **Path A (multi-tenant RLS):** 2-3 months build, 1.5 FTE — blocks POC mode until Month 3-4
- **Path B (container-per-customer):** 1-2 weeks, 1 FTE — stopgap, not scalable past 15-20 customers
- **Path C (Teras as infrastructure):** VoronCitadel deploys as application on Teras platform

# Decision

Teras AI Platform is the infrastructure layer. VoronCitadel deploys as an application ON Teras.

## What Teras Provides (Eliminating Build Requirements)

| Dependency | Original Plan | Teras Resolution |
|---|---|---|
| Multi-tenant data isolation | 2-3 month RLS build | Teras deployment capability |
| API gateway | HoE builds | Teras API Gateway exists |
| Governance infrastructure | HoE builds | Teras governance layer exists |
| DevOps/SRE hire | 0.5-1.0 FTE | Teras team (Farul's) handles infra |
| AI RAG pipeline | HoE + Jr Backend build | Teras provides RAG infrastructure |

## Remaining Dependencies (Application-Layer Only)

1. UI/UX + white-labelling — HoE + Jr Backend
2. Connector suite — Jr Backend under HoE direction
3. VoronCitadel-Teras integration — HoE (first integration)

## Governance Boundary

- **Teras governs:** AI usage (guardrails, identity, audit, API access, model routing)
- **VoronCitadel governs:** Organizational risk (GRC, compliance frameworks, risk quantification)
- **Integration point:** VoronCitadel uses Teras identity/audit for user access; VoronCitadel's GRC layer is its own domain

# Rationale

1. Time to first POC: 2-3 weeks (vs 2-3 months for Path A)
2. FTE reduction: 3 FTE (vs 5 FTE without Teras)
3. Enterprise-grade: Teras has governance, audit, air-gapped deployment — beyond what container-per-customer provides
4. Sovereign: on-premise NVIDIA RTX PRO 6000 Blackwell, all data within Malaysia

# Alternatives Considered

- **Path A (multi-tenant RLS):** Rejected — 2-3 month timeline blocks POC mode too long
- **Path B (container-per-customer):** Rejected as permanent solution — operational complexity unmanageable past 5 instances without DevOps
