# DEC-20260822-004 — MQL Definition

## Definition

**MQL = "Requested a Meeting"**

Binary. No interpretation. No vanity.

## Funnel Architecture

```
1,300 stakeholders (universe)
      ↓  marketing: awareness & nurture
260 engaged (20%)
      ↓  marketing: conversion to MQL
  MQL = requested a meeting
      ↓  sales/BD: meeting held → POC → close
78 meetings → 23 POCs → 7 sales
```

## Ownership Boundary

| Stage | Owner | KPI |
|-------|-------|-----|
| Universe → Engaged | Marketing | Engagement rate (20% target) |
| Engaged → MQL | Marketing | MQL count (meeting requests generated) |
| MQL → Meeting held | Sales/BD | Meeting conversion rate (30%) |
| Meeting → POC | Sales/BD | POC conversion rate (30%) |
| POC → Close | Sales/BD | Close rate (30%) |

## What This Resolves

1. **Layer 2 budget contention (DEC-20260822-002):** Marketing's deliverable is now defined — MQLs. Budget is justified against MQL targets.
2. **260→78 gap ownership:** The engaged→MQL conversion gap now has a named owner (marketing). Previously unowned.
3. **Vanity metric risk:** Binary definition prevents "awareness" and "engagement" from being used as proxy outcomes.
4. **Tuesday meeting frame:** DAF walks in with one question — "how many MQLs at what cost?"
