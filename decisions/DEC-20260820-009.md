# Context

DEC-20260820-008 established Teras as infrastructure layer for VoronCitadel POC deployments. DAF now extends this decision to cover all three CyberSecurity Practice products. Each product has distinct infrastructure needs that Teras addresses differently.

# Decision

**All three CyberSecurity Practice products deploy on Teras AI Platform as their infrastructure layer.**

```
CTO (Farul — STK-20260803-006)
├── Teras — Infrastructure Layer
│   ├── GPU Compute (NVIDIA RTX PRO 6000 Blackwell)
│   ├── AI Services (LLM, RAG, Vision, Speech, OCR, Translation)
│   ├── Governed AI Platform (Identity, API Gateway, Guardrails, Audit)
│   └── Applications (Akal Suite, Developer APIs)
│
└── CyberSecurity Practice (Sovereign Org, aligned with CTO)
    ├── Practice CTO: Fuad (STK-20260804-003)
    ├── VoronCitadel — GRC & Digital Risk Quantification [on Teras]
    ├── GovSec-TIP — National Cyber Threat Intelligence Platform [on Teras]
    └── ChainSentry — Blockchain Forensics & Investigative Workbench [on Teras]
```

# Product-by-Product Teras Leverage

## 1. VoronCitadel (GRC & Digital Risk Quantification)

**Current state:** Single-tenant Docker Compose, Node.js + Express + PostgreSQL, sovereign LLM via Aras (Qwen 3.5-27B)

| Teras Layer | What VoronCitadel Gains |
|---|---|
| GPU Compute | LLM inference for Sovereign AI Copilot (narrative gen, evidence drafting, coverage suggestion, cross-referencing) |
| AI Services | RAG infrastructure for AI Copilot context assembly; Model Registry for Qwen 3.5-27B serving |
| Governed Platform | API Gateway (replaces custom); Identity & Access (7 roles, 30 permissions); Audit & Compliance infrastructure |
| Deployment | Multi-customer deployment isolation (eliminates RLS build); Air-gapped capability for gov clients |

**Eliminates:** Multi-tenant RLS build, DevOps hire, API gateway build, governance infrastructure build, RAG pipeline build
**Time to first POC:** 2-3 weeks (vs 2-3 months)

## 2. GovSec-TIP (National Cyber Threat Intelligence Platform)

**Current state:** Node.js + Express + PostgreSQL, single-tenant, AI Analyst via OpenAI-compatible endpoint (model.arasintegrasi.ai), RAG context assembly in-house, 12 scheduled pipelines

| Teras Layer | What GovSec-TIP Gains |
|---|---|
| GPU Compute | LLM inference for AI Analyst (NL queries, automated insights, case AI); NLP auto-classification pipeline |
| AI Services | RAG infrastructure (replaces in-house context assembly); Model Registry; Translation (for multi-language intel); Speech (for audio evidence) |
| Governed Platform | API Gateway (147 endpoints across 23 modules); Identity & Access (RBAC, classification levels: Rahsia/Sensitif/Terhad/Pertidahan/Awam); Audit & Compliance (immutable audit trail, SIEM integration) |
| Deployment | Multi-agency deployment isolation (each gov agency gets isolated instance); Air-gapped capability (critical for classified intel) |

**Key acceleration:** AI Analyst RAG context assembly already in-house — Teras provides the GPU and model serving layer. Teras governance layer maps directly to Malaysian classification levels. Air-gapped deployment is a hard requirement for national intel platforms — Teras claims this capability.

**Eliminates:** Custom RAG infrastructure scaling, API gateway for 147 endpoints, classification-level enforcement infrastructure (Teras has it), separate audit/compliance build
**Enables:** Multi-agency deployment (each agency = Teras-managed instance), air-gapped classified deployment

## 3. ChainSentry (Blockchain Forensics & Investigative Workbench)

**Current state:** Containerized app, PostgreSQL, single Linux host, LLM for assisted classification (~20s), evidence processing, dossier composition, self-hostable inference endpoint

| Teras Layer | What ChainSentry Gains |
|---|---|
| GPU Compute | LLM inference for assisted classification (currently ~20s — Teras GPU + optimised kernel could cut to ~5-8s); dossier composition |
| AI Services | RAG for dossier assembly (cited assessments); OCR for evidence processing (image evidence); Translation for non-native content; Model Registry |
| Governed Platform | API Gateway (44 route handlers); Identity & Access (5 roles); Audit trail (privileged action recording); RBAC with tenant isolation |
| Deployment | Multi-organisation deployment isolation (each tenant = Teras-managed instance); Air-gapped for sensitive investigations |

**Key acceleration:** ChainSentry's assisted classification at ~20s is a UX bottleneck — Teras GPU + optimised serving kernel (20-25% throughput boost) directly improves this. OCR and translation are already needed for evidence processing — Teras provides these as services. Multi-tenant isolation is a known gap (only 1 tenant verified) — Teras resolves this at infrastructure level.

**Eliminates:** Self-hosted inference endpoint management, multi-tenant isolation verification, custom OCR/translation pipeline
**Enables:** Faster classification (GPU acceleration), multi-tenant scaling, air-gapped investigative deployments

# Dependencies & Open Questions

1. **Teras team capacity** — Can Farul's team support 3 product deployments simultaneously? (Critical — was open question for VoronCitadel alone, now 3x)
2. **Teras pricing model** — Is infrastructure cost absorbed by Farul's org, charged per product, or revenue-shared? (Financial model assumes zero Teras cost to CyberSec Practice)
3. **Integration sequencing** — VoronCitadel first (already planned), GovSec-TIP second, ChainSentry third? Or parallel?
4. **Teras-VoronCitadel integration status** — Has anyone built VoronCitadel to run on Teras yet? (Still open from DEC-20260820-008)
5. **GovSec-TIP Teras integration** — GovSec-TIP's AI Analyst already uses Aras LLM endpoint. Is the Teras integration just formalising existing relationship, or is it a new build?
6. **ChainSentry Teras integration** — ChainSentry is the most self-contained product. What's the integration priority vs the other two?
7. **GPU capacity** — 3 products sharing GPU pool. Qwen3.5-397B at 605 tok/s (16 users) — can this serve 3 products' AI workloads simultaneously?
8. **Teras multi-app deployment** — Teras currently runs Akal Suite. Can it run 3 more apps (VoronCitadel, GovSec-TIP, ChainSentry) without architecture changes?
