# Decision Record

## SRS Key Technical Findings

- **Data platform:** PostgreSQL (relational) + Neo4j (graph) + Qdrant (vector)
- **Agent runtime:** Eternis (scheduling, pipeline execution, inter-agent events, run logging)
- **Sentiment:** MTizer (proprietary Malay/English sentiment with confidence)
- **Content integrity:** MiroFish (fact-checking, misinformation verification)
- **Speech-to-text:** MEMber Suara STT (Malay-primary)
- **Prediction:** Anchored ensemble + LLM reasoning with time-decaying weights + omega adjustment
- **R.I.S.I.K integration:** SR-CHT-05 — configurable analytical framework in conversational AI
- **Multi-tenant:** Each engagement = isolated configuration-driven tenant
