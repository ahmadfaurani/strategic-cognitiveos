# Context

Honcho's memory infrastructure was running all 11 LLM components on Qwen3.5-397B-A17B. This worked (833 work units completed) but was inefficient: the deriver took ~4 hours to process the queue because each extraction call spun up a 397B model. Dialectic levels were supposed to represent different reasoning depths but all used the same model, meaning "minimal" cost as much as "max."

Additional issues: 3 duplicate copies of DIALECTIC_LEVELS MODEL lines in .env, 2 duplicate TEI embedding blocks, and no fallback models for any component.

# Decision

Implement three-model tiering:

| Tier | Model | Components | Active Params |
|------|-------|-----------|---------------|
| Session | GLM-5.2 | OpenClaw conversation | — |
| Deep reasoning | Qwen3.5-397B-A17B | Dialectic medium/high/max, dream deduction/induction | 17B |
| Light tasks | Qwen3.6-35B-A3B | Deriver, summary | 3B |
| Light dialectic | Qwen3.6-27B | Dialectic minimal/low | 27B (dense) |
| Embedding | BAAI/bge-m3 | Vector embeddings | — (local TEI) |

All components get Qwen3.5-27B as fallback. Duplicate .env lines cleaned (3→1 for dialectic, 2→1 for TEI). Legacy "Custom LLM Provider Configuration" block removed.

# Rationale

- **Deriver throughput:** 3B active params (35B-A3B) vs 17B active (397B) = ~10x faster per work unit. 833 units that took 4 hours should complete in ~25 min.
- **Dialectic tiering:** minimal/low on 27B saves compute for simple observations. medium/high/max stay on 397B for genuine deep analysis.
- **Summary:** compression task, not generation — 35B-A3B is sufficient.
- **Resilience:** fallbacks on all components mean a single model being unavailable doesn't take down the pipeline.
- **Config hygiene:** duplicate lines removed, single source of truth per component.

# Alternatives Considered

1. **Status quo (397B for everything)** — rejected: slow deriver, no tiering, no fallbacks
2. **Qwen3.6-27B for deriver** — rejected: 27B dense is slower than 35B-A3B MoE (3B active)
3. **Kimi-K3 as alternative model** — rejected: less tested with Honcho, uncertain tool-calling support
