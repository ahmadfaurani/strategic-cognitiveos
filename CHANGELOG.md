# Changelog

All notable changes to Strategic CognitiveOS are documented here.

## [1.0.0] — 2026-07-25

### Added — Phase 1 Implementation Pack

- **Specification:** Complete 34-section foundational operating specification (`spec-v1.md`)
- **Governance:** 6 governance documents covering operating principles, decision rights, information classification, record lifecycle, portfolio governance, and contribution standard
- **Schemas:** 8 JSON schemas for canonical record types (strategic-memory, decision, initiative, stakeholder, commitment, action, intelligence, risk)
- **Taxonomies:** 7 YAML taxonomy files (tags, missions, portfolio-tiers, readiness-levels, statuses, priorities, sensitivity-levels)
- **Templates:** 10 Markdown templates for record types (conversation, decision, initiative, stakeholder, engagement, commitment, action, intelligence, risk, outcome)
- **Notion:** 6 Notion database definitions (Executive Portfolio, Strategic Actions, Stakeholder Intelligence, Decision Register, Product Readiness, Risks and Blockers)
- **Repository:** Full directory structure per specification
- **Indexes:** 7 initial index files

### Phase 1 Scope

- 14 canonical record types
- 23 tag namespaces
- 10 mission tags
- 4 portfolio tiers
- 8 readiness levels
- 6 attention levels
- 9-step capture workflow
- 4-week execution plan
