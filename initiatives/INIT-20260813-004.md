# Summary

Tripartite collaboration between UPM (AI research / Agentic AI Framework), Aras (AI compute infrastructure + platform + cybersecurity productisation), and CSM (cybersecurity domain authority + operational validation). Potentially one of the highest strategic-value workstreams in the CSM–Aras portfolio.

# Tripartite Architecture

| Party | Contribution |
|-------|-------------|
| **UPM** | AI research, Agentic AI Framework |
| **Aras** | AI compute infrastructure (~32 cluster nodes), platform, cybersecurity productisation |
| **CSM** | Cybersecurity domain authority, operational validation |

# Strategic Vision

The UPM Agentic AI Framework has been discussed as potentially capable of being positioned as a **national-grade / Mythos-class AI capability**, subject to:
- Technical validation
- Appropriate NACSA/MKN consideration

# Pre-Positioning Validation Checklist

Before any national-grade positioning, the following must be obtained from UPM:

1. Architecture
2. Models
3. Cybersecurity capabilities
4. Deployment architecture
5. Maturity assessment
6. Operational use cases
7. Security controls
8. Infrastructure requirements

**STATUS UPDATE (Aug 18):** CSM has formally requested items 1-6 from UPM (DEC-20260818-010, CONV-20260818-004). Proposal due Sep 11, 2026. Items 7-8 to be assessed during Aras evaluation phase. Readiness upgraded from Concept → Proposal Stage.

# Infrastructure

Aras has indicated access to approximately **32 AI-cluster nodes** to support experimentation. This connects to INIT-20260813-002 (AI Token Allocation) and INIT-20260813-003 (Sovereign AI PaaS).
