# Summary

Proposed strategic collaboration between UiTM Centre for Media and Information Warfare Studies and Aras Integrasi to AI-enable the R.I.S.I.K Framework (Reality, Issue, Sentiment, Influence, Kontra Narrative). The framework supports structured analysis, situational awareness, and informed decision-making within the broader context of Gerak Saraf and Perang Saraf (Malaysia's cognitive/information warfare initiatives). UITM contributes academic leadership, research expertise, and understanding of Malaysia's media, behavioural, and socio-cultural environment. Aras contributes AI, cybersecurity, and technology implementation capabilities. The collaboration targets a credible, governed, and operationally relevant national capability.

# Strategic Significance

This initiative is a direct AI enablement of a concept already in DAF's portfolio — the R.I.S.I.K Cognitive Campaign Framework (listed in Workstream D, INIT-20260725-004, currently at concept stage). The UITM collaboration upgrades R.I.S.I.K from a concept to a structured, academically-grounded, AI-enabled national capability.

Three converging missions:
1. **Political & Strategic Intelligence** — R.I.S.I.K is DAF's framework for cognitive campaign analysis; AI enablement makes it operationally viable at scale
2. **Government AI Adoption** — AI-assisted information warfare analysis is a sovereign AI use case for national security
3. **Institutional Partnerships** — UITM (academic) + Aras (technology) + PMO (government oversight) = tri-sector collaboration

The CC'ing of two PMO officials (Khairil Hilmi Bin Mokhtar, Dr. Noor Dasrafeezal Bin Abdul Shukur) signals that this initiative has PMO-level visibility and strategic interest. This is not a routine academic partnership — it carries national security implications.

# KKOM System (Target)

**KKOM** = GovComms Command Center — the live system that operationalises R.I.S.I.K doctrine.
- **RISIK** is the doctrine (methodology). **KKOM** is the system (technology).
- **Static prototype:** 8 screens at mock-up-db-kkom-0752.myrisik.duckdns.org — COMPLETED
- **Current state:** HTML with manually typed data, no database, no back-end, no API
- **Target state:** Live data, back-end + database, API + documentation, reports from system
- **7-step pathway:** Modul RISIK → Static prototype (✅) → Upgrade decision → Knowledge transfer → Phased building → Integration & UAT → Delivery
- **5-stage build:** Data foundation → Back-end + API → Front-end → Reports & export → Full integration
- **Governance cycle:** TULIS → BINA → SEMAK → LULUS per stage (RISIK team writes, developer + companion builds, RISIK team reviews personally, written pass/fail decision)
- **Critical assumption:** Internal technical team must companion developer throughout — without this, doctrine integrity fails

# AI Capability Mapping (3 Priority Use Cases)

1. **Signal Collection & Grading Engine** (Layer R) — Automate OSINT/SOCMINT collection, auto-grade A-F, auto-classify narratives per 5-type ladder. Doctrine compliant: analyst reviews every signal.
2. **Issue Decomposition Assistant** (Layer I) — AI-assisted signal grouping, boundary suggestion, neutral naming. Human makes all decisions.
3. **Reference Poisoning Monitor** (NEW, §2.5.4) — Track what AI chatbots say about monitored entities. First-mover: no commercial product does this.

**Doctrine compliance (§2.5):** AI is NOT a fourth discipline. Accountability stays with analyst. AI output not citable as source. Every claim traced to origin. Declare AI influence. Treat monitored content as untrusted.
