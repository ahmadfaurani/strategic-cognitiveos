# Summary

Automated political news collection from 25+ Malaysian sources using Crawl4AI + Firecrawl fallback. Feeds into signal registry, daily briefs, and weekly synthesis for the Johor PRN 2026 monitoring system.

# Strategic Significance

Political intelligence requires continuous data collection. DeerFlow automates scraping from 25+ Malaysian news sources, processes headlines through entity tagging and signal grading, and feeds structured data into the memory system. The unified scraper uses Crawl4AI (stealth mode) as primary engine with Firecrawl as fallback for anti-bot-blocked sites.

# Mission Alignment

# Objectives

- Collect from 25+ Tier 1 and Tier 2 Malaysian news sources
- Achieve 100% success rate on daily collection runs
- Feed into PIR entity tagger for signal classification
- Support daily brief generation and weekly synthesis
- Maintain <5 min collection time for full 25-source run

# Scope

**In Scope:** Web scraping infrastructure (Crawl4AI + Firecrawl), 25-source operational collection script, entity tagging and signal grading, signal registry (JSONL format), benchmark and performance monitoring.

**Out of Scope:** Political analysis (downstream consumers handle this), social media monitoring (MiroFish handles this separately), ground-level intelligence.
