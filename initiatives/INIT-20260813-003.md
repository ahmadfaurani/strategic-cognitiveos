# Summary

A wider commercial architecture established through earlier discussions. The model being explored is essentially a 4-layer Sovereign AI PaaS relationship between Aras and CSM, creating a potential recurring PaaS / managed sovereign AI relationship rather than isolated project revenue.

# 4-Layer Commercial Architecture

```
Layer 1: Sovereign Infrastructure
    Aras provides compute / model infrastructure.
        ↓
Layer 2: AI Platform
    API routing, models, security, monitoring and lifecycle management.
        ↓
Layer 3: Managed Services
    Operational support, AI assurance and potentially threat-intelligence operations.
        ↓
Layer 4: Applications
    GovSec, VoronCitadel, CSM applications and future jointly developed solutions.
```

# Commercial Envelope

A first-year commercial envelope around **RM688,000** had previously been discussed as part of this evolving model.

This track should be kept separate from individual product sales because it can become the underlying commercial infrastructure supporting several CSM initiatives simultaneously.

# Strategic Significance

This is not a single product sale. It's a recurring platform relationship where Aras provides the infrastructure layer and CSM (and potentially other government clients) build on top. The PaaS model creates:

1. **Recurring revenue** — infrastructure access fees, platform management fees
2. **Stickiness** — CSM applications become dependent on Aras infrastructure
3. **Ecosystem multiplier** — each new CSM application or service increases platform value
4. **Sovereign positioning** — Malaysian government AI runs on Malaysian infrastructure
