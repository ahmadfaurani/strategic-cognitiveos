# Summary

A structured, tool-independent memory standard for AI-assisted continuity across conversations, decisions, projects, stakeholders, and documents. Uses GitHub as canonical authority, Obsidian for navigation, Notion for operations, and AI layer for processing.

# Strategic Significance

AI assistants wake up fresh each session. File-based memory (MEMORY.md, daily notes) works but lacks structure, schema validation, and cross-referencing. PI-OS creates a permanent, searchable, validated record system that survives session resets and platform changes. It is the infrastructure for persistent intelligence.

# Mission Alignment

- Knowledge management
- Organisational capability building
- Strategic planning infrastructure

# Objectives

- Create a universal memory card format for all captured information
- Maintain a decision registry with rationale, alternatives, and review triggers
- Track projects, stakeholders, and actions in a standardised schema
- Enable cross-referencing and knowledge graph navigation
- Enforce truth validation (CVS) on all analytical outputs

# Scope

**In Scope:** Schema definitions (memory card, decision, action, stakeholder), controlled taxonomy (tags, statuses, priorities, sensitivity), templates for all record types, governance documents (operating principles, classification, lifecycle, contribution), index files for navigation, GitHub as canonical store.

**Out of Scope:** Real-time data processing pipelines (DeerFlow handles this), political analysis content (lives in MEMORY.md and war room briefs), operational security tooling (Voron-Campaign, HOI handle this).
