# Summary

Seat-level political intelligence monitoring for Johor state election (PRN) 2026. Covers multiple constituencies with war room briefs, demographic analysis, turnout modelling, and candidate profiling.

# Strategic Significance

Johor PRN 2026 is a critical state election with implications for federal coalition dynamics. DAF requested seat-level war room analysis covering demographics, historical results, candidate profiles, and strategic assessments. Six seats analysed in Phase 1: N41 Puteri Wangsa, N16 Sungai Balang, N17 Semerah, N24 Senggarang, N33 Tenggaroh, N32 Endau.

# Mission Alignment

- Political intelligence collection and analysis
- Election monitoring capability
- Intelligence-driven decision support

# Objectives

- Produce war room briefs for targeted constituencies
- Model turnout scenarios and vote split dynamics
- Track candidate profiles and campaign narratives
- Monitor media signals via DeerFlow pipeline
- Deliver actionable intelligence for decision-making

# Scope

**In Scope:** Constituency-level demographic analysis, polling district (PD) breakdowns, historical result comparisons (2013/2018/2022), candidate profiling, turnout scenario modelling, vote split analysis, media signal collection (DeerFlow).

**Out of Scope:** Campaign strategy recommendations (DAF's domain), real-time polling (not available), ground intelligence (no field operations).

# Key Deliverables

- Phase 2: Signal Pipeline (in-progress) — DeerFlow + signal registry + heartbeat integration
- Phase 3: Daily Briefs (pending) — Awaiting pipeline stabilisation
