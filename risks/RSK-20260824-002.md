# Risk Description

The ~24-entity federation model discussed for Bursa Malaysia carries several unvalidated assumptions:

1. **Shared-vendor model** — Proposed common-vendor model has not been tested against actual participant vendor inventories
2. **Architecture capacity** — Whether VoronCitadel/Teras architecture can support 24-entity federation has not been validated
3. **Bursa acceptance** — Whether Bursa would accept the federated architecture for sectorial oversight is unknown
4. **Commercial assumptions** — The federation model implies commercial implications (licensing, data sharing, tenant isolation) that have not been validated

While DAF has formally designated the 24-entity model as a hypothesis (DEC-20260824-002), there is a risk that stakeholders treat it as committed scope in discussions, planning, or commercial conversations.

## Risk Category

**Delivery capacity / Architecture** — Unvalidated architectural assumptions driving scope overreach.

## Probability & Impact

- **Probability: Medium** — The formal designation as hypothesis (DEC-20260824-002) provides some protection, but the compelling nature of the vision creates pull toward treating it as committed
- **Impact: Medium** — If treated as committed, the POC overextends, timeline fails, and the Bursa reference account opportunity is damaged

## Mitigation

1. DEC-20260824-002 formally designates the 24-entity model as hypothesis
2. Validation Phase includes explicit gates before Scale Decision
3. Shared-vendor model must be validated against actual participant vendor inventories
4. This risk record provides audit trail for the designation
