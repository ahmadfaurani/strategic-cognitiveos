# Risk Description

Bursa Malaysia's proposed four-month timeline for the VoronCitadel POC creates timeline compression risk across multiple workstreams:

1. **TPRM development** — VoronCitadel is POC-ready but TPRM-specific features may need enhancement for Bursa's sectorial context
2. **Shared vendor validation** — Requires actual participant vendor inventory data, which is not yet available
3. **Federated compliance document check** — Aggregation architecture needs development
4. **Validation Phase** — URD/SRS, architecture validation, Bursa acceptance, and scale decision all need to complete within or shortly after the 4-month window

## Risk Category

**Timing** — The 4-month window is aggressive for a multi-phase POC involving federated architecture.

## Probability & Impact

- **Probability: Medium** — The TPRM-first approach mitigates by grounding Phase 0 in proven capability, but the cumulative scope across phases is significant
- **Impact: High** — Timeline failure would damage the first CSM-channel POC, the Bursa reference account opportunity, and CSM channel credibility

## Mitigation

1. TPRM-first approach limits Phase 0 to proven VoronCitadel capability
2. Fuad tasked with targeted development (ACT-20260824-001) with explicit priority planning
3. Validation Phase includes Scale Decision gate — federation scope can be deferred if timeline pressure threatens quality
4. Phased progression allows partial value delivery even if full timeline is not met
5. 3–4 organisation scope (vs 24-entity) reduces integration complexity
