# Risk Description

Strategic initiatives are launched with strong momentum but lose traction without systematic follow-through. The 90-day agenda from the professional assessment identified this pattern. Without weekly executive review and accountability mechanisms, initiatives drift.

# Risk Category

governance

# Related Initiative

PRJ-20260725-F001 — Workstream F: Organisational Capability Building

# Probability

Medium — structural risk, some evidence of pattern

# Impact

High — initiatives die from neglect, not from wrong direction

# Risk Assessment

**High (Probability: Medium × Impact: High)**

The gap between strategy and execution is where most initiatives fail. CognitiveOS is designed to close this gap but only if it's actually used.

# Mitigation Strategy

1. Implement weekly executive review (ACT-20260802-006)
2. Track every initiative with a named owner and next action
3. Flag stalled initiatives (>14 days no update = blocked)
4. Portfolio tier review every 30 days — demote stalled initiatives

faurani-jaafar

# Status

identified

# Trigger Conditions

- Initiative has no update for >14 days
- Action items have no owner assigned
- Weekly review not held for 2 consecutive weeks
