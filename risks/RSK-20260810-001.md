# Risk Statement

Hadri has not been officially onboarded yet, but is named as the incoming delivery owner for GovSec TIP (INIT-20260810-003), the GovSec × TI Integration (INIT-20260804-003), and both downstream initiatives (Score Card INIT-20260810-001, CBOM Agent INIT-20260810-002). The development handover (ACT-20260810-005) and CyberDSA Product Launch Checklist (ACT-20260810-006) both depend on his availability. If Hadri's onboarding is delayed beyond ~Aug 24, the CyberDSA launch readiness window compresses to ~5 weeks, which may be insufficient for handover assimilation + launch preparation.

# Risk Owner

DAF (Director, Cyber Security Practice) — owns the hiring and onboarding decision.

# Affected Initiatives

- INIT-20260810-003 — GovSec CyberDSA Product Launch Readiness (critical dependency)
- INIT-20260804-003 — GovSec × TI Integration (delivery owner)
- INIT-20260810-001 — Cybersecurity Score Card Framework (delivery owner)
- INIT-20260810-002 — CBOM Agent (delivery owner)

# Likelihood

Medium — Hadri is already engaged via email and FYI'd on this directive, but official onboarding (contract, access provisioning, start date) is not confirmed.

# Impact

Critical — if Hadri is not onboarded by late August:
- Handover documentation cannot be formally received and acknowledged
- CyberDSA Product Launch Checklist cannot be produced (ACT-20260810-006)
- Delivery ownership transfer cannot occur
- Fuad must continue as sole technical owner, splitting time between hardening and handover support
- All four CSM collaboration tracks lose their designated delivery owner

# Mitigation

1. **Prioritise Hadri's onboarding** as a critical path item — escalate to HR/management if needed
2. **Begin handover documentation immediately** (ACT-20260810-005) so it's ready when Hadri arrives
3. **Interim delivery ownership:** Fuad continues as delivery owner until Hadri is onboarded
4. **Remote engagement:** Hadri can begin producing the CyberDSA Launch Checklist (ACT-20260810-006) before official onboarding if access can be provisioned
5. **Knowledge transfer sessions:** schedule 2-3 sessions in the first week of Hadri's onboarding for walkthrough of architecture, codebase, and demo flow

# Monitoring

- Weekly check on onboarding status during August
- If not onboarded by 2026-08-24, escalate to DAF for direct intervention
- If not onboarded by 2026-08-31, reassess CyberDSA launch feasibility and consider contingency (Fuad as demo owner, Hadri as post-launch delivery owner)
