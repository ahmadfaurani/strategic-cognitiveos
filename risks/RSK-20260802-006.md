# Risk Description

Fuad Kamarazaman (Principal AI Security Architect) owns GovSec (50%), DRQ/ISOLens (40%), ChainSentry (5%), LE-UIP (5%), plus R&D (20% time). This is a single-person dependency for the majority of cybersecurity product delivery. If Fuad is unavailable, product development stalls across the BU.

**Update (10 Aug):** Hadri (Lead Architect, STK-20260803-007) is now absorbing technical architecture ownership. Fuad is compiling handover documentation (ACT-20260810-005) for Hadri. This reduces but does not eliminate the Fuad concentration — Hadri receives knowledge, but Fuad still owns active development until handover completes.
