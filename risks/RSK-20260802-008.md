# Risk Description

The portfolio contains 20+ initiatives across 6 workstream clusters, many at concept stage. Without strict portfolio gating, resources spread across too many low-readiness initiatives, preventing any from reaching pilot-ready or delivery-ready.

# Risk Category

governance

# Related Initiative

PRJ-20260725-F001 — Workstream F: Organisational Capability Building

# Probability

High — current state, many concepts active simultaneously

# Impact

Medium — no single initiative fails, but none accelerate either

# Risk Assessment

**Medium (Probability: High × Impact: Medium)**

Not catastrophic individually, but cumulatively prevents portfolio progression.

# Mitigation Strategy

1. Apply portfolio tier framework: Tier 1 gets resources, Tier 2 gets bounded validation, Tier 3 gets intelligence only
2. Monthly portfolio review — promote/demote between tiers
3. Cap active initiatives at 3 flagship + 5 incubation at any time
4. Kill or defer initiatives that have been concept-stage for >6 months

# Mitigation Owner

faurani-jaafar

# Status

**Mitigating** — Portfolio tier framework now actively enforced via CognitiveOS. Product readiness index tracks all products. Development freeze (DEC-20260810-002) forces focus on flagship (GovSec TIP) rather than diluting across concept-stage products. Tier 2/3 initiatives are being maintained as intelligence rather than active development.

**Related mitigations:**
- Product readiness index — enforces tier gating
- DEC-20260810-002 — Development freeze concentrates effort
- Portfolio tier framework — Tier 1/2/3 classification enforced

# Trigger Conditions

- More than 3 Tier 1 initiatives active simultaneously
- Tier 2 incubation initiatives consuming delivery resources
- No initiative has advanced a readiness gate in 30 days
