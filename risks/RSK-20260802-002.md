# Risk Description

DAF is the strategic owner, relationship owner, document drafter, and decision-maker for most active initiatives. If he is unavailable (illness, travel, competing priority), progress halts across the portfolio. This is a single-point-of-failure risk at the human level.

# Risk Category

resource-constraint

# Related Initiative

PRJ-20260725-F001 — Workstream F: Organisational Capability Building

# Probability

High — structurally inherent in current setup

# Impact

High — total portfolio stall if DAF is unavailable for >1 week

# Risk Assessment

**Critical (Probability: High × Impact: High)**

The system depends on one person's continuous availability and cognitive capacity. This is not sustainable for institutional growth.

# Mitigation Strategy

1. Identify second-line owners for each workstream cluster
2. Document institutional knowledge in CognitiveOS so it survives personnel changes
3. Build a deputy system — at minimum, one person who can cover stakeholder communications
4. Create decision-rights matrix clarifying what can be decided without DAF

# Mitigation Owner

faurani-jaafar

However, DAF remains strategic owner across all 6 clusters — delegation to product/programme managers still incomplete. Hadi onboarding (RSK-20260810-001) would further reduce DAF load.
