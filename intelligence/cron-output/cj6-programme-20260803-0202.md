## Analytical Assessment (for Aras Integrati positioning)

1. **Curriculum is NOT greenfield.** CyberSecurity Malaysia's CyberSAFE/CyberGuru/Global ACE/CSM-CP/ISCB stack is an existing, accredited curriculum-and-certification backbone. A Community Champions curriculum should be positioned as an *extension/localisation layer* on top of these assets (awareness tier via CyberSAFE, skills tier via CyberGuru, accreditation via Global ACE/CSM-CP), not a from-scratch build. This materially de-risks the RM 100K curriculum budget.

2. **Community/NGO partner already exists and is summit-integrated.** MCCO (500+ members, 40+ partners, rawSEC technical arm) is an official CYDES partner and holds a session at NCSS 2026. This is a ready-made community-delivery channel for champions recruitment, grassroots training, and CTF/mentorship. Aras Integrati's value-add is curriculum/programme *design and accreditation architecture*, not community mobilisation (MCCO owns that).

3. **KPM/KPT collaboration** was not surfaced publicly this cycle — the search backend returned only generic results. This remains a gap to pursue via direct outreach or monitoring of MOE/MOHE announcements. Existing CyberSecurity Malaysia "Academia" track and ISCB suggest a relationship exists but is not publicly detailed.

4. **G2G/ASEAN positioning is a confirmed strength.** CYDES/NCSS is a proven, large-scale (27 countries, 70 VIP delegations) platform run by NACSA/NSC. CSCDC's G2G briefing and ASEAN cyber diplomacy mandate is well-served by this existing infrastructure. Aras Integrati should position around *content/curriculum* for these briefings rather than the convening itself.

5. **JURUS is the key precedent to study.** NACSA's JURUS pilot-graduate model (awarded at NCSS 2026) is the closest public analogue to a trained-champion cohort with a graduation/certification ceremony. Securing JURUS programme details (curriculum, selection, scale) should be a priority intelligence target for the next cycle.

6. **International benchmarking blocked this cycle.** Singapore/UK/Australia community champion model queries returned no usable results. Recommend next cycle attempt direct extraction of: csa.gov.sg (SG Cyber Youth / Cyber Security Awareness), ncsc.gov.uk (Cyber First / Cyber Aware community programmes), cyber.gov.au (Australian Cyber Security Centre awareness/partnership programmes).
