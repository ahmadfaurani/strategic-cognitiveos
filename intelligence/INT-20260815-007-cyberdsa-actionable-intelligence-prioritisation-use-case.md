## PART 1: THE PROBLEM §7 SOLVES

### Without the Standard (Anti-Pattern §44)

A typical CyberDSA update might say:

> *"We need to finalise positioning, get meetings sorted, make sure demos work, follow up with CSM, and track our leads."*

This violates 6 anti-patterns simultaneously:
- ❌ Treats request as independent (no correlation to other criteria)
- ❌ Summarises without extracting implications
- ❌ Generates low-value actions (no owner, no deadline, no evidence)
- ❌ Confuses meetings with outcomes ("get meetings sorted")
- ❌ Allows ambiguous ownership ("we")
- ❌ Accepts implied "ongoing" as meaningful status

### With the Standard (Doctrine §7)

The same information becomes **10-element actionable intelligence**:

| Element | Content |
|---------|---------|
| **SIGNAL** | Positioning statement draft exists but unsigned (4.1) |
| **EVIDENCE** | INT-002 Criterion 4.1, status "draft exists"; CP1 deadline Aug 22 |
| **PATTERN** | Leverage point — one sign-off unblocks 4 criteria (4.2, 4.4, 4.5, 4.6). Compounding — enables entire marketing workstream. Strategic window — 7 days to CP1. |
| **IMPLICATION** | Azza cannot produce one-pagers (4.2), demo materials (4.4), sovereign narrative (4.5), or campaign launch (4.6) until this is signed. Marketing workstream at 0% pending one decision. |
| **OPPORTUNITY** | 15-minute action (review + sign) unblocks 4 criteria = 8.5% of total mission |
| **CONFIDENCE** | [HIGH] — draft exists, DAF authored the positioning direction |
| **DECISION WINDOW** | Before Aug 22 (CP1). Ideally today. Each day of delay = downstream criteria compress. |
| **RECOMMENDED ACTION** | DAF reviews existing draft, signs off or provides revision direction in writing |
| **OWNER** | DAF |
| **VERIFICATION** | Signed-off positioning document accessible to Tier 1. Azza confirms receipt and begins 4.2. |

**The difference:** The first version is a sentence. The second is an execution package. Someone can pick it up, act, and be held accountable to an evidence standard.

## PART 3: PRIORITISATION ENGINE (§8) — WEIGHTED SCORING

### The 7-Dimension Model

| Dimension | Weight | What It Measures |
|-----------|--------|-----------------|
| Strategic Impact | 25% | Does this advance the core mission? |
| Time Criticality | 15% | Is there a closing window? |
| Portfolio Leverage | 15% | Does this unblock other work? |
| Commercial / Mission Value | 15% | Does this generate revenue or mission outcome? |
| Dependency Unlock | 10% | How many downstream criteria are freed? |
| Stakeholder Importance | 10% | Does this affect key relationships? |
| Risk Reduction | 10% | Does this reduce mission failure probability? |

Each dimension scored 1-5. Weighted score = Σ(dimension × weight).

## PART 4: FROM INTELLIGENCE TO EXECUTION — THE CHAIN

### How Raw Signal Becomes Verifiable Outcome

```
SIGNAL (what happened)
  ↓
EVIDENCE (what proves the signal is real)
  ↓
PATTERN (what structural relationship does this reveal?)
  ↓
IMPLICATION (why does this matter beyond the immediate?)
  ↓
OPPORTUNITY/RISK (what could happen if we act / don't act?)
  ↓
CONFIDENCE (how certain are we? [HIGH/MEDIUM/LOW])
  ↓
DECISION WINDOW (when does action need to occur?)
  ↓
RECOMMENDED ACTION (what specifically should be done?)
  ↓
OWNER (who is accountable?)
  ↓
VERIFICATION (what evidence proves the action produced the intended result?)
```

### Applied Example: The Full Chain for A1 (Positioning)

| Stage | Output |
|-------|--------|
| **SIGNAL** | Draft positioning statement exists, not signed off |
| **EVIDENCE** | INT-002 §4.1 status: "draft exists"; CP1 deadline Aug 22; INT-005 Metric 3 |
| **PATTERN** | Leverage Point (P4) — 1 action / 4 criteria unblocked. Compounding (P10) — enables 4 downstream deliverables. Strategic Window (P5) — 7 days to CP1. |
| **IMPLICATION** | Marketing workstream at 0%. Azza blocked. Without sign-off: 4 criteria RED at CP1 → cascade to CP2 → no one-pagers, no demo materials, no campaign, no sovereign narrative for event. |
| **OPPORTUNITY** | 15-minute action unblocks 8.5% of mission + activates entire marketing dimension |
| **RISK** | Each day of delay compresses downstream: Azza needs 2 weeks for one-pagers (4.2), 2 weeks for demo materials (4.4), 1 week for narrative (4.5). If signed Aug 19 (3 days late), all downstream deadlines compress by 3 days. |
| **CONFIDENCE** | [HIGH] — draft exists, DAF authored direction, zero analysis needed |
| **DECISION WINDOW** | Today. Maximum Aug 19 (3 days before CP1). |
| **RECOMMENDED ACTION** | DAF reviews draft, signs off or revises in writing, circulates to Tier 1 |
| **OWNER** | DAF |
| **VERIFICATION** | Signed document accessible to Tier 1. Azza confirms receipt. 4.2 status changes to "in progress" within 24 hours. |

**This is why §7 exists:** The signal "positioning draft exists" is useless on its own. The 10-element chain transforms it into an execution package with owner, deadline, risk, and verification standard.

### Conflict 1: Urgency vs Importance

| Action | Urgency | Importance | Engine Resolution |
|--------|---------|------------|-------------------|
| A1 (positioning) | 5/5 (7 days to CP1) | 5/5 (4 criteria) | No conflict — both high. Score: 4.45 (#1) |
| A4 (demo scope) | 5/5 (7 days to CP1) | 4/5 (1 criterion + 4 downstream) | Time-critical but lower leverage. Score: 3.55 (#4) |

**Doctrine §8:** *"When urgency conflicts with importance, explicitly identify the conflict."*

A4 is equally urgent (CP1 deadline) but less important (fewer criteria unblocked). Engine correctly ranks A1 above A4 despite same time criticality — because Strategic Impact and Portfolio Leverage differ.

### Conflict 2: Two Equal Scores, Different Effort

A2 (PC appointment) and A3 (193-org framework) both score 4.35. But:

| Factor | A2 (PC) | A3 (193-org) |
|--------|---------|--------------|
| Effort | One conversation + mandate doc | 48 hours of analytical work |
| Reversibility | Reversible (can reassign) | Not reversible (framework becomes reference) |
| Resource availability | Depends on Kenny | Ember has capacity now |

**Doctrine §8:** *"Then evaluate: effort, confidence, reversibility, resource availability."*

**Resolution:** Execute in parallel. A2 is DAF's action (conversation). A3 is Ember's action (framework). No resource contention. Both start now.

### Conflict 3: The Programme Coordinator Ripple Effect

A2 (PC appointment) scored 4.35. But it also affects:

| Downstream Effect | Mechanism | Affected Actions |
|-------------------|-----------|------------------|
| Tracker ownership transfers to PC | Metric 7 → A7 owner changes | A7 |
| Weekly review facilitation | Action #7 from coverage plan | A7 |
| DAF bandwidth freed | DAF can focus on A1, A5 | A1, A5 |
| CSM coordination formalised via Amelia-Aisha | Reduces A5 coordination overhead | A5 |

**Insight:** A2's true score is higher than 4.35 if you account for second-order effects. The engine scores direct impact; the pattern recognition layer (§6) captures compounding effects. This is why the Cognitive Loop runs both — §8 scores, §6 contextualises.

## KEY TAKEAWAY

**The doctrine's value is not in producing reports. It's in preventing the wrong actions from being prioritised.**

Without §7 and §8, the natural response to CyberDSA's complexity is to create a task list — everything looks equally important, ownership is ambiguous, and "ongoing" becomes the default status.

With the standard:
- Raw signals become 10-element intelligence packages with owners and verification
- Prioritisation is transparent and reproducible (not "this feels urgent")
- The highest-leverage actions are explicitly identified (not just the loudest)
- Verification prevents false completion claims
- Anti-patterns are structurally blocked

**The 15-minute action (A1) scores highest. The 48-hour action (A3) ties for second. The engine rewards leverage, not effort.**
