1. **Copy this template** to daily memory file (`memory/YYYY-MM-DD.md`) at each heartbeat
2. **Fill in metrics** based on collection status
3. **Check triggers** in `collection-plan.json` for any fired alerts
4. **Escalate immediately** if CRITICAL trigger fires (Meta activation, regulatory action)
5. **Log completed sync** with timestamp

**Escalation Path:**
- CRITICAL → Telegram alert to operator + Flash Alert within 4 hours
- HIGH → Email to legal/security + Policy Brief within 24 hours
- MEDIUM → Log to Weekly Synthesis
