## 1. Strategic Shift: One-to-One → Multi-Layer Coverage

The plan's core recommendation replaces the current one-to-one CSM-Aras relationship model with a **four-layer stakeholder coverage architecture**:

| Layer | Purpose |
|-------|---------|
| Primary relationship owner | Accountable for continuity, relationship context, action closure |
| Secondary / operational cover | Ensures actions continue when primary unavailable; supports coordination cadence |
| Technical / commercial specialist | Joins for product, architecture, AI platform, commercial, marketing expertise |
| Executive escalation | Organisational authority, resource commitment, issue resolution |

**Target state:** Each priority CSM stakeholder has ~3 active Aras relationship paths (relationship/programme, specialist, executive/commercial).
