# Intelligence Record

## Technical Architecture

### Data Platform (3 stores)
- **PostgreSQL** — relational: articles, sentiment snapshots, ground sessions, predictions, accounts, agent logs, schedules, segment scores
- **Neo4j** — graph: topic/area/actor nodes, co-occurrence + relationship edges, powers Topic Network + influence mapping
- **Qdrant** — vector: embeddings of articles, knowledgebase, ground notes, powers semantic search + RAG citations

### Data Cascade
COLLECT → REFINE → LAKE → SERVE (collect-once, refine-in-stages, serve-everywhere)

### AI/ML Components
| Component | Function | R.I.S.I.K Extension |
|-----------|----------|-------------------|
| Eternis runtime | Agent orchestration (scheduling, pipeline, inter-agent events, logging) | New R.I.S.I.K agents plug in here |
| MTizer | Malay/English sentiment scoring with confidence | Extend for emotion/trust/behavioural intent (Layer S) |
| MiroFish | Content integrity / misinformation verification | Extend for SAMAR indicators (Layer R) |
| MEMber Suara STT | Malay speech-to-text | HUMINT voice input (Layer R) |
| Prediction model | Anchored ensemble + LLM reasoning | Adapt for issue triage (Layer I) |

### R.I.S.I.K Integration Point
**SR-CHT-05:** Guided-interview service — configurable analytical framework (R.I.S.I.K named), pulls platform evidence per step, emits structured intelligence report with conclusion.

This is configuration of existing conversational AI + RAG, not new development.
