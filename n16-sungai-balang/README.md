## 📊 Seat Overview

N16 Sungai Balang is a **BN-defensive / contestable** seat in the Muar coastal–semi-rural belt. The seat features:

- **73.6% Malay voters** (22,857) — Decisive bloc
- **25.1% Chinese voters** (7,780) — Critical PH base
- **28.1% Youth 18-30** (8,736) — Mobilization opportunity
- **50.6% Female voters** (15,703) — Cost-of-living messaging priority

**2022 Result:** BN won by 2,293 votes (12.6% margin) with 61.8% turnout  
**2018 Result:** BN won by 174 votes (0.9% margin) with 84.9% turnout
