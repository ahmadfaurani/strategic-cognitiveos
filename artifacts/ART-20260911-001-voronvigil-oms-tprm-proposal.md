# Summary

VoronVigil is a Malaysia-hosted, Sovereign AI-enabled Third-Party Risk Management platform designed to manage and continuously assure OMS providers used by Bursa Malaysia Participating Organisations — supplier compliance, contractual assurance, service monitoring, evidence management and trust-risk quantification within one governed platform.

| Area | Summary |
|------|---------|
| Problem | OMS supplier oversight fragmented across contracts, service reports, DR evidence, assessments, operational systems — regulatory assurance reactive |
| Core Solution | OMS-specific supplier registry, contract/control mapping, evidence repository, performance monitoring, remediation workflow, audit trail, compliance pack |
| Regulatory Alignment | ITSS 10.3/10.4 — supplier agreements, security obligations, incident management, audit rights, testing, performance monitoring, BCP/DR |
| Sovereign AI | Private AI in Malaysia-hosted environment (evidence extraction, clause mapping, analysis, report drafting); deterministic engines calculate authoritative scores; humans approve consequential decisions |
| CTDM | Cyber Trust Degradation Model — Trust Exposure, Exploitability, Dependency, Impact Amplifier, Trust Recovery Capability |
| Assessment Unit | PO × OMS Provider × OMS/Service Arrangement |
| Outputs | OMS-specific compliance packs, management dashboards, audit evidence, remediation tracking, Board-level reporting |
| Implementation | Six phases: Mobilise → Compliance Foundation → Sovereign AI → Service Assurance → CTDM → Continuous Assurance |
| Immediate Decision | Approval to commence Phase 0–1 (OMS inventory, regulatory control framework, evidence repository, contract assessment, compliance pack capability) |
