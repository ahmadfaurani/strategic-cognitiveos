## 🔍 Quick Reference by Use Case

### "I need to send an email to PMO"

1. Check `01-engagement-tracker/email-registry.md` for prior threads
2. Use `05-session-materials/cover-email-template.md` for draft
3. Log sent email in `memory/pmo-email-registry.md`

### "I need to prepare for the working session"

1. Review `99-quick-start.md` for next actions
2. Check `01-engagement-tracker/action-items.md` for tasks
3. Use `07-templates-tools/pilot-scoring-matrix.md` for prioritisation
4. Prepare demos using `03-ai-cohort-program/model-catalog.md`

### "I need to understand governance requirements"

1. Start with `06-governance-security/ai-governance-checklist.md`
2. Review `04-datalake-initiative/architecture-outline.md` for security architecture
3. Check `memory/pmo-datalake-readiness-assessment.md` Section 2 for compliance

### "I need to understand the Data Lake initiative"

1. Read `04-datalake-initiative/architecture-outline.md` for framework
2. Review `memory/pmo-datalake-readiness-assessment.md` for assessment
3. Check `02-strategic-context/bahagian-data-strategik-mandate.md` for context

### "I need to track what we're doing"

1. Daily check: `99-quick-start.md` for next actions
2. Weekly check: `README.md` for status dashboard
3. Task updates: `01-engagement-tracker/action-items.md`
