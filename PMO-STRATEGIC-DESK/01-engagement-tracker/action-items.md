## 🔄 Update Procedure

### When to Update

- ✅ Immediately after completing an action
- ✅ When status changes (Pending → In Progress → Complete)
- ✅ When adding new actions (e.g., from meeting outcomes)
- ✅ Daily check-in (review overdue/at-risk items)
- ✅ Weekly review (update metrics, reprioritise)

### How to Update

1. Open `01-engagement-tracker/action-items.md`
2. Find relevant action by ID
3. Update status column
4. Add completion date if done
5. Add notes if context changed
6. Update metrics table at bottom
7. Save file

### Status Legend

| Symbol | Meaning | Definition |
|--------|---------|------------|
| 🔥 | **NEXT / In Progress** | Active work happening now |
| ⏳ | Pending | Waiting to start |
| ✅ | Complete | Fully done, outcome documented |
| 🚫 | Blocked | Cannot proceed due to external dependency |
| ⚠️ | At Risk | May miss deadline, mitigation needed |
