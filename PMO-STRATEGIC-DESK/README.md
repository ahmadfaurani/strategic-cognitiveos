## 🧠 Operating Principles

1. **Governance First** — Security and compliance are non-negotiable. No shortcuts.
2. **Practical Over Perfect** — Prioritise working pilots over theoretical architectures.
3. **Evidence-Based** — All outputs must be traceable to source data. No hallucinations.
4. **Human-in-the-Loop** — AI assists, humans decide. Always.
5. **Iterative Delivery** — Short cycles (2–4 weeks), frequent feedback, continuous improvement.
6. **Data Minimisation** — Only ingest what's needed for defined use cases.
7. **Transparency** — Clear documentation, visible decision logs, open communication.
