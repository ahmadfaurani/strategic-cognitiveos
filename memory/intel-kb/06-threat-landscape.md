## 1. Threat Taxonomy Overview

PMO BKS classifies information operations threats along **two operational dimensions**:

| Dimension | Categories |
|-----------|------------|
| **Timeline** | Acute (Short Horizon) vs. Chronic (Long Horizon) |
| **OODA Phase Target** | Observe, Orient, Decide, Act |

---

## 2. Acute Cognitive Disruption (Short Horizon)

**Definition:** High-velocity, high-impact injects designed to trigger immediate panic, mask moving kinetic threats, or force reactive sub-optimal government policy adjustments.

**Time Window:** Minutes to days

**Target OODA Phases:** **Observe** + **Act**

---

### 2.1 Threat Types

#### AT-001: Synthetic Executive Impersonation
| Attribute | Description |
|-----------|-------------|
| **Method** | Deepfake video/audio of PM, DPM, or senior officials issuing false orders |
| **Delivery** | Social media (X, TikTok, Telegram), leaked to sympathetic outlets |
| **Intent** | Trigger market panic, force premature policy response, create constitutional crisis |
| **Historical Precedent** | [Classified - case studies pending] |
| **BKS Countermeasure** | Cryptographic verification anchors, rapid takedown via MCMC, immediate public rebuttal |
| **ESC Code** | ESC-001 (CRITICAL) |

---

#### AT-002: Synthetic Financial Runs
| Attribute | Description |
|-----------|-------------|
| **Method** | AI-generated "breaking news" of bank insolvency, currency collapse, or capital controls |
| **Delivery** | Coordinated bot amplification, fake news sites mimicking legitimate outlets |
| **Intent** | Trigger actual bank runs, currency volatility, capital flight |
| **Historical Precedent** | 2023 US regional bank crisis (Twitter rumor → actual run) |
| **BKS Countermeasure** | Pre-bunking with Bank Negara coordination, rapid platform enforcement, liquidity assurance |
| **ESC Code** | ESC-001 (CRITICAL) |

---

#### AT-003: Emergency Fabrication
| Attribute | Description |
|-----------|-------------|
| **Method** | False reports of terrorist attacks, natural disasters, or military incursions |
| **Delivery** | SMS spoofing, social media, fake emergency alerts |
| **Intent** | Overwhelm emergency services, create public panic, mask concurrent kinetic operations |
| **Historical Precedent** | 2018 Hawaii missile false alarm |
| **BKS Countermeasure** | Coordination with NADMA/PDRM for official alerts, public education on verified channels |
| **ESC Code** | ESC-001 (CRITICAL) |

---

#### AT-004: Infrastructure False Flag
| Attribute | Description |
|-----------|-------------|
| **Method** | Claim responsibility for cyberattacks/outages that are actually natural failures |
| **Delivery** | Hacktivist forums, Telegram channels, leaked "manifestos" |
| **Intent** | Escalate tensions, justify retaliatory measures, test response protocols |
| **Historical Precedent** | Various attributed/non-attributed cyber incidents globally |
| **BKS Countermeasure** | Forensic attribution before public statements, coordination with NACSA on technical assessment |
| **ESC Code** | ESC-002 (HIGH) |

---

## 3. Chronic Cognitive Conditioning (Long Horizon)

**Definition:** Campaigns that manipulate cultural, political, or religious fault lines over months or years to structurally degrade trust in public institutions, media validity, and social cohesion.

**Time Window:** Months to years

**Target OODA Phases:** **Orient** + **Decide**

---

### 3.1 Threat Types

#### CT-001: Institutional Trust Degradation
| Attribute | Description |
|-----------|-------------|
| **Method** | Sustained narrative campaign portraying government institutions as corrupt, incompetent, or illegitimate |
| **Delivery** | Mix of true scandals (amplified), half-truths, and fabricated evidence |
| **Intent** | Reduce public compliance with policies, create opening for alternative governance narratives |
| **Target Institutions** | SPRM, BNM, PDRM, Judiciary, Electoral Commission |
| **BKS Countermeasure** | Transparency initiatives, proactive disclosure, counter-narrative campaigns |
| **Detection Markers** | Coordinated amplification across platforms, bot networks, foreign language artifacts |
| **ESC Code** | ESC-003 (MEDIUM) - escalating to ESC-002 if acceleration detected |

---

#### CT-002: Social Cohesion Exploitation
| Attribute | Description |
|-----------|-------------|
| **Method** | Amplify racial, religious, or regional tensions through selective editing, context removal, fabrication |
| **Delivery** | Viral videos (often decontextualized), memes, inflammatory commentary |
| **Intent** | Fragment society along identity lines, reduce national resilience, create internal security burden |
| **Target Fault Lines** | Race (Bumiputera/non-Bumiputera), Religion (Islam/other faiths), Region (Peninsula/East Malaysia) |
| **BKS Countermeasure** | Interfaith/inter-racial coalition building, rapid fact-checking, community leader engagement |
| **Detection Markers** | Sudden amplification of historical grievances, bot accounts using localized dialects |
| **ESC Code** | ESC-002 (HIGH) - potential for kinetic escalation |

---

#### CT-003: Electoral Integrity Undermining
| Attribute | Description |
|-----------|-------------|
| **Method** | Pre-emptive narratives of electoral fraud, voter suppression, or foreign interference |
| **Delivery** | "Research reports," social media campaigns, sympathetic media outlets |
| **Intent** | Reduce legitimacy of electoral outcomes regardless of result, justify post-election unrest |
| **Target Events** | PRN (Johor 2026+), GE16 (Sabah), general elections |
| **BKS Countermeasure** | Election security task force, transparency measures, rapid response to false claims |
| **Detection Markers** | Pre-positioned narratives, coordinated timing across platforms |
| **ESC Code** | ESC-002 (HIGH) during election periods |

**Note:** Directly relevant to political monitoring pipeline (see `memory/n16-sungai-balang-war-room-brief-20260627.md`, etc.)

---

#### CT-004: Foreign Policy Sharp Power
| Attribute | Description |
|-----------|-------------|
| **Method** | State-sponsored narratives designed to manipulate bilateral relations, regional alliances |
| **Delivery** | State media, academic front organizations, think tank reports |
| **Intent** | Strain diplomatic relationships, reduce regional cooperation, create strategic openings |
| **Target Relationships** | ASEAN cohesion, Malaysia-Singapore relations, Malaysia-China-US balance |
| **BKS Countermeasure** | Wisma Putra coordination, public attribution of state actors, exposure of front organizations |
| **Detection Markers** | State media amplification, diplomatic cable correlations, funding trail analysis |
| **ESC Code** | ESC-003 (MEDIUM) |

---

#### CT-005: Media Ecosystem Poisoning
| Attribute | Description |
|-----------|-------------|
| **Method** | Flood information space with low-quality, contradictory, or emotionally manipulative content |
| **Delivery** | Fake news sites, compromised legitimate outlets, bot amplification |
| **Intent** | Create "liar's dividend" (nothing can be trusted), reduce public ability to make informed decisions |
| **Target** | General public, specific demographic segments |
| **BKS Countermeasure** | Media literacy campaigns, verified source promotion, platform algorithm advocacy |
| **Detection Markers** | Content velocity anomalies, coordinated posting patterns, semantic fingerprinting |
| **ESC Code** | ESC-004 (LOW) - chronic baseline threat |

## 5. Technology Threat Assessment

### Frontier AI Risks

| Capability | Current State (2026) | Projected (2027-2028) | BKS Preparedness |
|------------|---------------------|----------------------|------------------|
| **Text Generation** | Anthropic Mythos class, GPT-5 class | More coherent, harder to detect | ✅ Stylometric fingerprinting deployed |
| **Deepfake Video** | High quality, requires expertise | Consumer-grade, real-time | ⚠️ Detection improving, gap remains |
| **Deepfake Audio** | Near-perfect clone from short sample | Real-time voice conversion | ✅ Cryptographic verification anchors |
| **Micro-Targeting** | Demographic + psychographic | Individual-level persuasion | ⚠️ Platform cooperation critical |
| **Autonomous Agents** | Limited, scripted | Adaptive, goal-driven | 🔴 Research priority |
