### Sync Workflow

1. **20:00 UTC** - Git sync job runs
2. Checks for new/modified `.md` files
3. Stages all changes: `git add -A`
4. Commits with descriptive message:
   ```
   Daily sync: YYYY-MM-DD - [X] new reports
   
   - Daily reports: [N] files
   - Coalition analysis: [N] files
   - Constituency profiles: [N] files
   
   Classification: TLP:AMBER
   Campaign Day: D-[X]
   ```
5. Pushes to `origin/main`
6. Logs sync event to `.git-sync-log.txt`

### Exit Conditions

- **Success:** Files committed + pushed → Log entry written
- **No changes:** Exit silently (normal, no log entry)
- **Error:** Report to Telegram (auth failure, network issue, merge conflict)
