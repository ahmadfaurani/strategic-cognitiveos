# PKR War Room — Candidate Political Profile Template

**Classification:** TLP:AMBER — Operational Use Only  
**Version:** 1.0 (2026-06-28)  
**Purpose:** Maximum political impact intelligence for campaign strategy

---

## 🎯 Design Philosophy

This profile is **NOT** a biographical CV. It is a **weaponized intelligence document** designed to:

1. **Identify attack lines** against opponent candidates
2. **Expose vulnerabilities** in opponent narratives
3. **Map community networks** that drive votes
4. **Inform resource allocation** (where to invest, where to contain)
5. **Shape PH candidate narrative** (contrast, differentiation)
6. **Predict voter behavior** (who will vote for whom and why)

**Every section must answer:** "How does this help us win?"

---

- Ethnicity + religion → vote bloc alignment

- Incumbent status → track record weaponization

## 🔧 How to Use This Template

1. **Create candidate profile file:**
   ```bash
   mkdir -p src/data/candidate-profiles
   vim src/data/candidate-profiles/n17-mohd-fared.md
   ```

2. **Fill in all 10 sections** — incomplete profiles are useless

3. **Update CANDIDATES.md** with summary + link to full profile

4. **Update seat data file** with candidate object:
   ```typescript
   candidates: {
     bn: {
       name: 'Mohd Fared Mohd Khalid',
       coalition: 'BN',
       party: 'UMNO',
       incumbent: true,
       profile: 'See src/data/candidate-profiles/n17-mohd-fared.md',
       strengths: ['Incumbency', 'EXCO portfolio', 'Ketua Kampung networks'],
       vulnerabilities: ['Cost-of-living protest aggregator', 'Absentee ADUN narrative']
     }
   }
   ```

5. **Commit and push:**
   ```bash
   git add src/data/candidate-profiles/n17-*.md src/data/n17-semerah.ts
   git commit -m "Add Mohd Fared candidate profile — N17 Semerah"
   git push origin main
   ```

6. **Brief war room team** — profile is only useful if it's read and acted upon

## 📊 Profile Quality Checklist

Before submitting a candidate profile:

- [ ] All 10 sections completed
- [ ] Strengths have evidence + impact + PH response

- [ ] Vote ceiling/floor are realistic (not hopeful or pessimistic)
