## 📋 Provider Evaluation Checklist

### **Technical Requirements**
```markdown
## API & Integration
- [ ] REST API with comprehensive documentation
- [ ] Webhook support for real-time events
- [ ] SDK availability (Node.js, Python, PHP, etc.)
- [ ] Rate limits clearly defined
- [ ] Sandbox/testing environment

## AI & Automation
- [ ] Native AI chatbot (not third-party integration)
- [ ] RAG/document-grounded responses (not generic GPT)
- [ ] No-code chatbot builder
- [ ] Intent recognition & entity extraction
- [ ] Human handoff capability

## Data & Compliance
- [ ] Data residency options (EU, Malaysia, etc.)
- [ ] DPA (Data Processing Agreement) available
- [ ] GDPR/PDPA compliance documentation
- [ ] Data retention policies
- [ ] Encryption at rest & in transit
```

### **Business Requirements**
```markdown
## Pricing & Contract
- [ ] Transparent pricing (no hidden markups on Meta fees)
- [ ] No long-term contract (or flexible terms)
- [ ] No setup fee (or reasonable one-time cost)
- [ ] Free trial or demo available
- [ ] Scalable pricing (grows with volume)

- [ ] Onboarding assistance (templates, verification)
- [ ] Support channels (chat, email, phone)
- [ ] Support hours (24/7 vs business hours)
- [ ] Response time SLA
- [ ] Dedicated account manager (for enterprise)
```

## ⚠️ Common Pitfalls to Avoid

### **Pricing Traps**
1. **Hidden Markups:** Some BSPs advertise "low platform fee" but markup Meta conversation fees 20-50%
   - **Fix:** Ask explicitly: "Do you markup Meta conversation fees?"

2. **Per-Seat Pricing Explosion:** $49/month sounds cheap until you need 10 agents ($490/month)
   - **Fix:** Model total cost at expected team size

3. **Setup Fees:** MessageBird charges $600+ setup; others charge $0
   - **Fix:** Negotiate setup fee waiver or choose $0-setup provider

4. **Minimum Contracts:** 12-36 month locks for enterprise plans
   - **Fix:** Start with monthly, negotiate annual discount after validation

### **Technical Pitfalls**
1. **Template Rejection:** Marketing content in utility templates
   - **Fix:** Separate templates by category, review Meta guidelines

2. **Quality Rating Degradation:** High block rate from purchased lists
   - **Fix:** Only send to verified opt-in contacts

3. **Webhook Failures:** Incoming messages lost due to misconfigured webhooks
   - **Fix:** Test webhook endpoint before launch, implement retry logic

4. **Number Porting Downtime:** 4-24 hours downtime during migration
   - **Fix:** Schedule migration during low-traffic period, notify customers

### **Compliance Pitfalls**
1. **Invalid Opt-in:** Assuming email/SMS consent applies to WhatsApp
   - **Fix:** Obtain channel-specific WhatsApp opt-in

2. **Data Residency Violations:** EU/Malaysia data stored in US without safeguards
   - **Fix:** Choose provider with regional data centers or SCCs

3. **Template Category Misuse:** Using authentication templates for marketing
   - **Fix:** Submit templates with correct category, accept Meta review decisions
