## 📧 Email Communication Guidelines

### Domain Selection

| Context | Recommended Domain | Rationale |
|---------|-------------------|-----------|
| Inter-agency (government) | @mkn.gov.my | MKN is parent agency, recognized across government |
| Operational (NACSA internal) | @nacsa.gov.my | Agency-specific, operational matters |
| NC4 Crisis Coordination | @nc4.gov.my | Distinct crisis centre identity |
| External (international) | @nacsa.gov.my | Clear agency identification |

### Email Etiquette

| Recipient Level | Salutation | Tone | Expected Response Time |
|-----------------|-----------|------|------------------------|
| CEO | "YBhg. Ketua Eksekutif" | Formal, concise | 24-72 hours (via PA) |
| Pengarah | "YBhg. Pengarah" | Formal, professional | 24-48 hours |
| KPP | "Puan/Encik [Name]" | Professional, direct | 12-24 hours |
| PPK/PPTM | "Puan/Encik [Name]" | Professional, collaborative | 12-24 hours |

### Email Subject Line Conventions

```
[URGENT] — Critical incident, immediate attention required
[HIGH] — Priority matter, 24-hour response expected
[NORMAL] — Routine inquiry, 48-hour response expected
[INFO] — Informational, no response required
[MEETING] — Meeting request or coordination
```

**Example:**
```
[URGENT] Ransomware Incident — [Organization Name] — [Date/Time]
[HIGH] CII Security Audit Request — [Sector] — [Timeline]
[NORMAL] Partnership Inquiry — [Organization] — [Topic]
```

## 📱 Phone Communication Guidelines

### Best Practices

| Practice | Recommendation |
|----------|----------------|
| **Timing** | Avoid calls outside 08:00-18:00 unless urgent |
| **Preparation** | Have incident details ready before calling |
| **Documentation** | Follow up phone calls with email summary |
| **Escalation** | Respect chain of command unless emergency |
| **Language** | Bahasa Malaysia preferred, English acceptable |

### After-Hours Protocol

| Time | Protocol |
|------|----------|
| 18:00-22:00 | Call only for Level 2+ incidents |
| 22:00-08:00 | Call only for Level 3+ incidents (national crisis) |
| Weekends/Holidays | Same as after-hours — urgency-based |

### Voicemail/Unanswered Calls

```
If no answer:
1. Leave brief voicemail (name, organization, callback number, urgency level)
2. Send follow-up email referencing the call
3. Wait 30 minutes for callback (urgent) or 2 hours (routine)
4. Escalate to alternate contact if no response
```

## 🎯 Communication Security

### Recommended Practices

| Practice | Implementation |
|----------|----------------|
| **Encryption** | Use PGP/GPG for sensitive email (if available) |
| **Verification** | Verify phone numbers before sharing sensitive info |
| **Need-to-Know** | Limit incident details to relevant personnel |
| **Documentation** | Log all crisis communications for post-incident review |
| **Secure Channels** | Use classified channels for classified information |

### What NOT to Do

| ❌ Avoid | ✅ Instead |
|----------|-----------|
| Send sensitive info via unencrypted email | Use secure file transfer or encrypted email |
| Share incident details on personal messaging apps | Use official channels only |
| Bypass chain of command for routine matters | Follow escalation protocol |
| Call multiple contacts simultaneously (creates confusion) | Designate single point of contact |
| Discuss incidents on non-secure phone lines | Use secure lines for classified matters |
