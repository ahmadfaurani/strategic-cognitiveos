# Lesson: OpenClaw Gateway V8 Heap Pressure

## Observation

During RADAR sweep at 2026-08-21 01:51 MYT, OpenClaw gateway (PID 518680) showed critical memory pressure after 2d 23h uptime:

- RSS: 3.29 GiB (104.9% of 3 GiB threshold)
- Event loop P99: 1.3-2.0 seconds (severe blocking)
- Liveness warnings: continuous every 30s
- Diagnostics snapshots: **disabled** — no early warning possible

## Root Cause

1. **No scheduled restart cadence** — gateway runs indefinitely until degradation
2. **Diagnostics disabled** — `memoryPressureSnapshot=false` means no heap snapshots captured before critical threshold
3. **V8 GC losing cycle** — under sustained allocation, GC cannot reclaim fast enough; each GC pause blocks the event loop, compounding latency
4. **Silent degradation** — process never crashed, just slowed. Every operation queued behind GC pauses. Operationally degraded but not detectable without RADAR sweep.

## Fix Applied

1. **Immediate**: Gateway restarted (PID 518680 → 2470705). RSS 3.29 GiB → 918 MB (72% reduction). Session recovered seamlessly.
2. **Preventive — RuntimeMaxSec**: Added `RuntimeMaxSec=172800` (48h) to systemd unit. Gateway auto-restarts before heap pressure accumulates.
3. **Preventive — Diagnostics**: Enabled `memoryPressureSnapshot: true` in openclaw.json. Future pressure events will capture heap snapshots for root cause analysis.

## Verification

- Post-restart RSS: 918 MB (within normal range)
- Zero memory pressure warnings post-restart
- Session recovery: `recovered=1 failed=0 skipped=0`
- Telegram provider, all 10 plugins loaded, port 28888 listening

## Generalization

This lesson applies to ALL long-running Node.js services in the stack:
- **DeerFlow gateway** (Node.js, same pattern risk)
- **Honcho deriver** (Python, different GC but same uptime risk)
- Any service running >48h without restart under sustained load

Pattern: **silent degradation > crash**. The most dangerous failure mode is one where the service stays "up" but operationally degraded. Monitoring must detect performance degradation, not just process death.
