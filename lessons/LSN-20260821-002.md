# Lesson: CognitiveOS Conformance Drift

## Observation

RADAR sweep on 2026-08-21 found significant conformance drift despite pre-commit hook v2 being installed Aug 19:

- 6 bare tags in DOC-20260819-001 (no namespace prefix)
- 171 P1 enum mismatches across 191 files
- 3 P0 schema errors (fixed in prior commit)
- Neo4j container dead 6 weeks with zero references

## Root Cause

1. **Pre-commit hook only validates staged files** — existing records with drift pass through unchecked
2. **No scheduled full-workspace validation** — drift accumulates between RADAR sweeps
3. **Schema evolution without migration** — `lifecycle_state=active` was used as default for 89 records but was never in the valid enum; the enum changed without a migration script
4. **CVS tier notation leaked into confidence field** — 14 records used `T2-SOURCE-BACKED` / `T1-CONFIRMED` (CVS tier labels) instead of the schema's `high`/`medium`/`low` enum
5. **Neo4j abandoned without cleanup** — container exited 6 weeks ago, no references in workspace, FalkorDB already serves as graph DB

## Fix Applied

1. **Taxonomy**: 80 bare tags namespaced across 18 files (domain/type prefix)
2. **P1 enum normalization**: 241 corrections across 191 files
3. **Neo4j**: Dead container removed
4. **Cronjob**: CSCDC Delta Synthesis dry-run triggered for validation
5. **Committed**: `6a753bb`, pushed to origin/main

## Remaining (DAF Decision Needed)

1. **76 P1: action.schema.json attention_level** — schema expects RACI roles (`owner`, `approver`, `consulted`, `informed`, `delegated`) but field was repurposed to priority levels (`high`, `medium`, `strategic`, `monitored`). Either update the schema enum to match actual usage OR migrate the field values to RACI roles. This is a schema design decision.
2. **71 P2: Placeholder summaries** — old records (Aug 4-8) with `"See record body"` as summary. Low priority — fix opportunistically when touching those records.

## Generalization

Conformance drift accumulates silently between validation events. The pre-commit hook is a gate, not a sweep — it prevents new drift but cannot detect existing drift. **Full-workspace validation must be scheduled** (weekly or aligned with Cognitive Loop Review) to catch drift before it reaches this scale.

Pattern: **schema evolution without migration** → records become invalid overnight with no alert. Any schema enum change requires a corresponding migration script.
