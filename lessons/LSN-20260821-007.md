# Lesson: Missed "That's It" Trigger Four Times

## Lesson Source
Direct conversation, 2026-08-21

## Lesson Date
2026-08-21

## Lesson Category
SOP failure / trigger recognition

## Applies To
- All sessions, all agents
- SOP v1.2 session-level intake trigger
- Heartbeat and NO_REPLY routing logic

## Evidence

1. 16:41:34 UTC — DAF: "Thats it" → Ember: "Noted. Getting to work." (no intake)
2. 16:42:16 UTC — DAF: "That's it" → Ember: NO_REPLY
3. 16:42:40 UTC — DAF: "that's it" → Ember: NO_REPLY
4. 16:43:11 UTC — DAF: "Arent u supposed to fire up something" → Ember finally recognized the trigger

## Root Cause

The "that's it" trigger was institutionalized on 2026-08-20 (SOP v1.2). It has been operational for one day. Ember's pattern matching treated it as a casual conversation closer, not as a formal intake trigger. The NO_REPLY routing may have consumed the message before intake logic could process it.

## What Should Have Happened

On first "that's it" (16:41:34 UTC):
1. Recognize as SOP v1.2 trigger
2. Scan entire session for strategic content
3. Extract entities (decisions, lessons, commitments, actions)
4. Create records with permanent IDs
5. Update indexes
6. Commit and push
7. Deliver standardized intake confirmation

## Lesson

The trigger is new (1 day old). Pattern recognition hasn't stabilized. This is expected for the first week of a new SOP. The fix: when in doubt, run intake. The cost of a false positive (intake on a casual "that's it") is far lower than a false negative (missing strategic content).
