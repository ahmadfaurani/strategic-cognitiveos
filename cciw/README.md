## Separation from Political Monitoring

| Aspect | Political Monitoring (DeerFlow) | CCIW |
|--------|--------------------------------|------|
| **Focus** | Real-time signals, narratives, sentiment | Institutional structures, doctrine, capabilities |
| **Timeline** | Daily/weekly collection | Quarterly/annual updates |
| **Output** | Signal Registry, Daily Briefs | Structural briefs, capability assessments |
| **Automation** | High (DeerFlow pipeline) | Manual/semi-automated research |
| **Validation** | Loop 2/3 grading | Multi-source verification, official docs |

---

## Access & Security

- **Classification:** Internal use only
- **Source Protection:** All claims must cite sources (URL, document, official publication)
- **Update Protocol:** Manual review before committing structural changes
- **No Automated Posting:** CCIW outputs do not auto-publish to channels
